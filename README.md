# lutzlstein's Omarchy themes

Custom themes for [Omarchy](https://omarchy.org), built with Aether.

## Backgrounds

Each theme's first background is AI-generated with ChatGPT by Cory Blische. The rest were generated by Cory Blische with [Oma Easel](https://github.com/lutzlstein/oma-easel), in the style and colors of the theme's original background. See each theme's README for the prompts. All backgrounds are released under the same MIT license as the themes.
